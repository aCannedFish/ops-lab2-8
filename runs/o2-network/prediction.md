# O2 测量前预测

记录时间：2026-11-03T13:17:46+08:00。

A 为 se-devops（192.168.0.134，x1e.2u.4g，2 vCPU/4 GiB）；B 为 se-devops2（192.168.0.142，x1.2u.4g，2 vCPU/4 GiB）。元数据中的 VPC ID 相同，两台分别在 cn-east-3a、cn-east-3c。B 直接通过内网请求 A，SSH 只用于操作与收集日志。

每次响应 256 KiB，即 262144 字节。到达率为 r 时，仅响应体所需带宽为 r × 262144 × 8 bit/s。100、250、400、500、700、1000、1500、2500 请求/秒分别需要约 0.210、0.524、0.839、1.049、1.468、2.097、3.146、5.243 Gbit/s，另有协议开销。尚未取得实例带宽配额，先用这些档位寻找吞吐平台，必要时再补充测量。

预计低负载时成功吞吐随到达率增加，接近可用带宽后 txkB/s 和成功吞吐趋于稳定，延迟和 TCP 发送队列上升。重传可能增加，但限速未必导致重传。同步检查两端 CPU 和发送滞后，区分网络瓶颈与压测端或服务端 CPU 瓶颈。每档 30 秒，随机种子 1，B 上 loadgen 使用两个核，A 上 enrolld 使用核 1。

通过 SSH 管理主机。本次在 A 的主机防火墙临时限制 TCP 8080，仅允许回环和 B 的内网地址，拒绝其他来源；结束后恢复原回环监听并删除本次规则。未操作云安全组，其规则不能由本次主机防火墙证据代替。
